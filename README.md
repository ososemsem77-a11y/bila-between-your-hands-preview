# بيلا بين إيديك — نسخة GitHub Pages

واجهة معاينة عربية لدليل مدينة ومركز بيلا، كفر الشيخ.

## فتح الموقع محليًا

افتح `index.html` في متصفح حديث. الخريطة التفاعلية تحتاج اتصالًا بالإنترنت لتحميل مكتبات Leaflet وخرائط OpenStreetMap.

## نشره على GitHub Pages

1. ارفع ملفات هذا المجلد إلى جذر مستودع GitHub عام.
2. افتح **Settings → Pages**.
3. اختر **Deploy from a branch**، ثم الفرع `main` والمجلد `/(root)`، واضغط **Save**.
4. بعد اكتمال النشر، افتح الرابط الذي يعرضه GitHub في صفحة Pages.

## حدود نسخة المعاينة

هذه ملفات واجهة ثابتة فقط. قائمة الأماكن فارغة حتى تُجمع بيانات محلية موثوقة ويُتحقق منها. الإدارة، تسجيل الدخول، الاقتراحات، الإحصائيات المشتركة وتخزين البيانات تحتاج إلى الخادم وقاعدة البيانات الموجودين في المشروع الكامل؛ لم تُضمّن هنا. لا توجد كلمة مرور أو بيانات خادم في مستودع الواجهة.
