# بيلا بين إيديك — نسخة GitHub Pages

واجهة عربية عامة لدليل مدينة ومركز بيلا، كفر الشيخ. تشمل البحث والتصنيفات، خريطة تفاعلية، رابط Google Maps الذي شاركه صاحب المشروع، بطاقات معلومات وروابط مصادر رسمية، ومعلومات تواصل منشورة لجهة حكومية.

## النشر

النسخة العامة منشورة عبر GitHub Pages من الفرع `main` والمجلد الجذر. ملف `static-data.js` يحتوي على المعلومات التي تظهر في النسخة الثابتة. أضف أي معلومة جديدة فقط بعد التحقق من مصدرها، وحدّث رابط المصدر ورابط Google Maps الخاص بالمكان.

## مصادر البيانات الحالية

- مسجد العارف بالله سيدي سالم البيلي أبو غنام: صفحة محافظة كفر الشيخ توثق افتتاحه بعد الترميم في فبراير 2025 وتذكر تاريخ إنشائه التقريبي. الرسم المرفق توضيحي وليس صورة فوتوغرافية للمسجد.
- مأمورية الضرائب المصرية ببيلا: العنوان ورقم الهاتف من صفحة مصلحة الضرائب المصرية.
- أرقام الطوارئ: صفحة دليل الخدمات بمحافظة كفر الشيخ.
- نقطة مدينة بيلا على Google Maps هي الرابط الذي شاركه صاحب المشروع.

تظهر المصادر داخل بطاقات المعلومات بالموقع:

- [محافظة كفر الشيخ — مسجد أبو غنام](https://kfs.gov.eg/posts/وسط-فرحة-الأهالي-محافظ-كفرالشيخ-يفتتح-مسجد-أبو-غنام-الأثري-ببيلا-مقدماً-التهنئة-لأبناء-المحافظة-بمناسبة-شهر-رمضان-المبارك)
- [مصلحة الضرائب المصرية — مأمورية بيلا](https://www.eta.gov.eg/ar/node/1010)
- [محافظة كفر الشيخ — دليل أرقام الطوارئ](https://kfs.gov.eg/index.php/directory)

## حدود النسخة العامة

هذه واجهة ثابتة على GitHub Pages؛ الأماكن المسجلة حاليًا قليلة وروابط كل مكان تفتح نتيجة بحثه في Google Maps لأن الإحداثيات الدقيقة غير متاحة. لا يوجد تسجيل دخول أو لوحة إدارة أو نموذج إرسال في هذه النسخة. المفضلة تحفظ على جهاز الزائر نفسه، ولا توجد قاعدة بيانات أو إحصائيات مشتركة. أضف بيانات جديدة بعد التحقق منها ثم انشر تحديثًا للملفات.
